🔰 0. Excel Basics & Core Fundamentals

Foundation Topics & Practice Qs
1. Excel Screen & Cell Address
Basics

Columns (A, B, C...) आणि Rows (1, 2, 3...) मिळून सेल तयार होतो (उदा. **A1**, **C15**).

Column Letter + Row Number (e.g. C15)
❓ Topic Practice Questions (२-३ प्रश्न)
प्र. १) कॉलम C आणि रो 15 जोडणाऱ्या सेलचा ॲड्रेस काय असेल? उत्तर: C15
प्र. २) निवडलेल्या सेलमधील ॲड्रेस स्क्रीनवर कुठे दिसतो? उत्तर: Name Box मधे
प्र. ३) Workbook आणि Worksheet मधील मुख्य फरक काय? उत्तर: Workbook म्हणजे पूर्ण फाईल, Worksheet हा त्यातील तक्ता.
2. Basic Data Types
Data Types

Text डावीकडे (Left), Number उजवीकडे (Right) अलाईन होतात. तारीख 1 Jan 1900 पासूनचा सिरीअल नंबर असते.

Text (Left) | Number (Right) | Date
❓ Topic Practice Questions
प्र. १) एक्सेल मध्ये नंबर आणि टेक्स्ट च्या अलाईनमेंट मध्ये काय फरक असतो? उत्तर: Text डावीकडे व Number उजवीकडे अलाईन होतो.
प्र. २) नंबर डावीकडे दिसत असेल तर त्याचा अर्थ काय? उत्तर: तो डेटा Text फॉरमॅटमध्ये सेव्ह झाला आहे.
3. Basic Arithmetic Operators
Arithmetic

बेरीज (`+`), वजाबाकी (`-`), गुणाकार (`*`), भागाकार (`/`), टक्केवारी (`%`), घातांक (`^`).

=A1+B1 | =A1-B1 | =A1*B1 | =A1/B1
❓ Topic Practice Questions
प्र. १) A1 मधील संख्येचे 15% काढण्याचा फॉर्म्युला काय? उत्तर: =A1*15%
प्र. २) `=10+5*2` चे उत्तर BODMAS नुसार काय येईल? उत्तर: 20 (आधी गुणाकार)
4. Cell Referencing ($ Sign)
Cell Lock

`F4` की दाबून सेल लॉक करणे. Relative (`A1`), Absolute (`$A$1`), Mixed (`$A1`).

Press F4 to lock cell ($A$1)
❓ Topic Practice Questions
प्र. १) फॉर्म्युला ड्रॅग करताना सेल लॉक करण्यासाठी कोणती की दाबतात? उत्तर: F4 Key ($A$1)
प्र. २) A1 मधील `=B1*10` फॉर्म्युला A2 मध्ये कॉपी केल्यास काय होईल? उत्तर: =B2*10 (Relative Reference)

🧠 1. Logical Functions & Error Handling

Decision Rules & Practice Qs
Basic IF Function
Basic

अट सत्य (True) की असत्य (False) तपासून निकाल देणे (उदा. Salary > ₹15,000).

=IF(C2>15000, 1000, 0)
❓ Topic Practice Questions
प्र. १) पगार > 15000 असल्यास 10% बोनस, नाहीतर 0 देणारा फॉर्म्युला लिहा. उत्तर: =IF(C2>15000, C2*10%, 0)
प्र. २) IF मध्ये value_if_false न लिहिल्यास काय उत्तर येते? उत्तर: FALSE
Nested IF (Multi-Slab)
Multi-Level

एकापेक्षा जास्त अटींच्या पातळ्या (उदा. Manager -> 5000, Supervisor -> 3000, Else -> 1000).

=IF(Desg="Manager", 5000, IF(Desg="Supervisor", 3000, 1000))
❓ Topic Practice Questions
प्र. १) Marks >= 75 -> "A", Marks >= 50 -> "B", Else -> "C" साठी फॉर्म्युला लिहा. उत्तर: =IF(A1>=75,"A",IF(A1>=50,"B","C"))
प्र. २) Nested IF मध्ये एकाच वेळी किती अटी जोडता येतात? उत्तर: 64 पातळींपर्यंत
IF with AND Function
Strict Logic

सर्व अटी एकाच वेळी सत्य असणे आवश्यक (उदा. Gender = Female AND Salary < 50,000).

=IF(AND(Gender="Female", Salary<50000), "Eligible", "Not")
❓ Topic Practice Questions
प्र. १) लिंग="Female" आणि पगार < 50000 असल्यास "Eligible" चा फॉर्म्युला लिहा. उत्तर: =IF(AND(A2="Female", B2<50000), "Eligible", "Not")
प्र. २) AND मध्ये 1 अट असत्य असेल तर काय निकाल येतो? उत्तर: FALSE
IFERROR Function
Error Handling

फॉर्म्युलामध्ये `#N/A` किंवा `#DIV/0!` एरर आल्यास त्याऐवजी कस्टम मेसेज किंवा 0 दाखवणे.

=IFERROR(A2/B2, 0)
❓ Topic Practice Questions
प्र. १) A1/B1 करताना `#DIV/0!` एरर लपवण्यासाठी कसा फॉर्म्युला लिहाल? उत्तर: =IFERROR(A1/B1, 0)
प्र. २) VLOOKUP मधील `#N/A` ऐवजी "Not Found" दाखवण्याचा फॉर्म्युला? उत्तर: =IFERROR(VLOOKUP(...), "Not Found")

📊 2. Counting & Aggregation Functions

Aggregations & Practice Qs
SUMIF & SUMIFS
Summation

अटींनुसार एकूण बेरीज करणे (उदा. North मधील Sales विभागाचा पगार).

=SUMIFS(Salary, Dept, "Sales", Region, "North")
❓ Topic Practice Questions
प्र. १) "Sales" विभागातील कर्मचाऱ्यांच्या पगाराची बेरीज कशी कराल? उत्तर: =SUMIF(Dept_Range, "Sales", Salary_Range)
प्र. २) SUMIF आणि SUMIFS मधील Sum Range कुठे लिहीतात? उत्तर: SUMIF मध्ये शेवटी, SUMIFS मध्ये सुरवातीला.
COUNTIF & COUNTIFS
Frequency

अटी पूर्ण करणाऱ्या नोंदी मोजणे (उदा. Cash व्यवहारांची संख्या).

=COUNTIFS(Type, "Cash", Mode, "Credit")
❓ Topic Practice Questions
प्र. १) Type="Cash" असलेल्या नोंदी मोजण्याचा फॉर्म्युला काय? उत्तर: =COUNTIF(Type_Range, "Cash")
प्र. २) पगार > 50000 असणाऱ्या कर्मचाऱ्यांची संख्या कशी मोजाल? उत्तर: =COUNTIF(Salary_Range, ">50000")
SUBTOTAL Function
Dynamic Filters

फिल्टर केलेल्या डेटावरच डायनॅमिक कॅल्क्युलेशन (Code 9 = SUM, 1 = AVERAGE).

=SUBTOTAL(9, Amount_Range)
❓ Topic Practice Questions
प्र. १) फिल्टर केलेल्या डेटाची बेरीज करण्यासाठी कोणता कोड वापरतात? उत्तर: Code 9 (किंवा 109)
प्र. २) SUBTOTAL मधील 9 आणि 109 मधील फरक काय? उत्तर: Code 109 मॅन्युअली लपवलेल्या Rows सोडतो.
SUMPRODUCT Function
Vector Product

नग (Quantity) × दर (Rate) गुणाकार करून थेट एकूण बेरीज काढणे.

=SUMPRODUCT(Qty_Range, Rate_Range)
❓ Topic Practice Questions
प्र. १) Qty आणि Rate चे स्वतंत्र गुणाकार न करता एकूण बेरीज कशी काढाल? उत्तर: =SUMPRODUCT(Qty_Range, Rate_Range)
प्र. २) Qty={5,10} आणि Rate={100,200} असल्यास SUMPRODUCT चे उत्तर काय? उत्तर: 2500 -> (5*100) + (10*200)

🔍 4. Lookup & Reference Analytics

Data Joining & Practice Qs
VLOOKUP (Exact Match)
Vertical Lookup

तक्त्यामधून आयडी किंवा नावावरून डेटा हुडकणे (`0` = Exact Match).

=VLOOKUP(A2, B2:D100, 3, 0)
❓ Topic Practice Questions
प्र. १) VLOOKUP मध्ये 3ऱ्या कॉलम मधील पगार शोधणारा फॉर्म्युला कसा लिहाल? उत्तर: =VLOOKUP(Emp_ID, Table, 3, 0)
प्र. २) Exact Match साठी शेवटचा आर्गुमेंट काय ठेवतात? उत्तर: 0 किंवा FALSE
प्र. ३) VLOOKUP ची मुख्य मर्यादा कोणती? उत्तर: तो फक्त डावीकडून उजवीकडे (Left-to-Right) डेटा शोधतो.
INDEX + MATCH Combination
Dynamic Lookup

VLOOKUP ची मर्यादा मोडून डाव्या बाजूचा डेटा शोधण्यासाठी (Left Lookup).

=INDEX(Salary, MATCH(Emp_ID, ID_Range, 0))
❓ Topic Practice Questions
प्र. १) डाव्या बाजूचा डेटा (Left Lookup) शोधण्यासाठी कोणते फॉर्म्युले वापरतात? उत्तर: INDEX + MATCH
प्र. २) MATCH फंक्शन काय शोधतो? उत्तर: शोधायच्या व्हॅल्यूची पोझिशन/नंबर.

💰 6. Financial Modeling & Risk Analytics

Banking & Practice Qs
PMT (Monthly EMI)
Loan EMI

कर्जाचा मासिक हप्ता काढणे. (Rate/12, Months, -Loan Amount).

=PMT(10%/12, 36, -100000)
❓ Topic Practice Questions
प्र. १) ₹1 लाख लोन, 10% दर व 3 वर्षांसाठी EMI काढण्याचा फॉर्म्युला? उत्तर: =PMT(10%/12, 36, -100000)
प्र. २) PMT मध्ये Loan Amount च्या आधी वजा (`-`) का लावतात? उत्तर: पॉझिटिव्ह EMI उत्तर येण्यासाठी.
IPMT vs PPMT
Interest & Principal

मासिक हप्त्यातील व्याजाचा भाग (IPMT) आणि मुद्दल भाग (PPMT) वेगळा करणे.

=IPMT(10%/12, 1, 36, -100000)
❓ Topic Practice Questions
प्र. १) पहिल्या महिन्याच्या EMI मधील व्याजाचा (Interest) भाग कसा काढाल? उत्तर: =IPMT(10%/12, 1, 36, -100000)
प्र. २) `IPMT + PPMT` ची बेरीज कशाच्या बरोबर असते? उत्तर: एकूण EMI (`PMT`) च्या बरोबर.
