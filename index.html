🧠 Module 1: Logical Functions Masterclass (सखोल लॉजिकल फॉर्म्युले)

1. IF Function Syntax & Deep Rules Logical
कन्डिशन तपासून TRUE किंवा FALSE आऊटपुट देण्यासाठी.
=IF(logical_test, value_if_true, value_if_false)
=IF(E5>=15000, E5*5%, 0)
=IF(Salary>=35000, "High Salary", "Standard")
💡 मराठीत स्पष्टीकरण: जर कर्मचाऱ्याचा पगार ₹१५,००० किंवा त्यापेक्षा जास्त असेल तर त्याला ५% बोनस द्या, नाहीतर ० द्या.
📌 महत्त्वाची टीप: Text आउटपुट कोटेशन "..." मध्ये असावे, पण नंबरसाठी कोटेशन वापरू नये!
2. IFS Function & Income Tax Slabs Excel 2019+
अनेक अटी (Multiple Conditions) एकाच फॉर्म्युल्यात मांडण्यासाठी (Nested IF चा आधुनिक पर्याय).
=IFS(condition1, val1, condition2, val2, ...)
=IFS(Income>=1000000, "30%", Income>=500000, "20%", Income>=250000, "5%", Income<250000, "NO TAX")
=IFS(Marks>=75, "Distinction", Marks>=60, "First Class", Marks>=35, "Pass", TRUE, "Fail")
💡 Income Tax Slab Logic: १० लाखांपेक्षा जास्त उत्पन्नावर ३०% टॅक्स, ५ ते १० लाखांवर २०%, २.५ ते ५ लाखांवर ५% आणि २.५ लाखांपेक्षा कमी उत्पन्नावर नो टॅक्स. शेवटची डिफॉल्ट कंडिशन देण्यासाठी TRUE, "Fallback" वापरावे.
3. AND & OR Truth Tables Multi-Condition
अनेक अटी एकत्र लॉजिकली जोडण्यासाठी.
=IF(AND(Branch="Borivali", Salary>=15000), "Eligible", "Not Eligible")
=IF(OR(Department="Sales", Department="Marketing"), "Sales Team", "Other")
=IF(AND(OR(Region="West", Region="South"), Revenue>50000), "Top Performers", "Regular")
💡 AND: सर्व अटी एकत्र पूर्ण झाल्या तरच TRUE आऊटपुट.
💡 OR: कोणतीही १ अट पूर्ण झाल्यास TRUE आऊटपुट.

📊 Module 2: Aggregations & Conditional Math/Stats

1. SUMIF vs SUMIFS Deep Breakdown Aggregation
अटीनुसार डेटाची अचूक बेरीज करणे.
=SUMIF(range, criteria, [sum_range])
=SUMIF(Designation, "Manager", Salary)
=SUMIFS(Amount, Transaction_Type, "Online", Debit_Credit, "Credit")
=SUMIFS(Revenue, Order_Date, ">=2025-01-01", Order_Date, "<=2025-12-31")
📌 काल्पनिक चूक टाळा: SUMIFS मध्ये पहिला पॅरामीटर sum_range (ज्या कॉलमची बेरीज करायची आहे) असतो, तर SUMIF मध्ये तो शेवटी असतो!
2. COUNT Family & Statistical Formulas Statistics
सेल्स मोजणी व नमुना स्टॅटिस्टिक्स.
=COUNT(Range) ➔ फक्त Numerical सेल्स मोजते
=COUNTA(Range) ➔ भरलेले सर्व सेल्स (Text + Number) मोजते
=COUNTBLANK(Range) ➔ रिकामे (Empty) सेल्स मोजते
=COUNTIF(Attendance_Range, "P") ➔ हजेरी मोजणे
=COUNTIFS(Dept, "IT", Location, "Pune") ➔ IT मधील पुण्याचे कर्मचारी
=LARGE(Salary_Range, 2) ➔ २ र्या क्रमांकाचा सर्वोच्च पगार
3. SUBTOTAL Function (Code 9 vs 109) Filtered Sum
फिल्टर केलेल्या डेटावर अचूक टोटल काढणे.
=SUBTOTAL(9, C3:C100) ➔ Filtered Visible Cells Total
=SUBTOTAL(109, C3:C100) ➔ Hidden Rows + Filtered Total
💡 सामान्य `=SUM()` वापरल्यास फिल्टर केलेले लपलेले रो देखील बेरीजमध्ये येतात. पण `=SUBTOTAL(9, ...)` फक्त स्क्रीनवर दिसणाऱ्या सेल्सचीच बेरीज करते!

💰 Module 5: Financial Functions & Loan Amortization

🔍 Module 8: Lookup & Reference Masterclass (VLOOKUP, XLOOKUP, INDEX+MATCH)

1. VLOOKUP Syntax & Limitations Traditional Lookup
उभ्या (Vertical) टेबलमधून डेटा शोधण्यासाठी.
=VLOOKUP(lookup_value, table_array, col_index_num, [range_lookup])
=VLOOKUP(A2, Lookup_Master!A:E, 3, FALSE)
⚠️ VLOOKUP च्या मर्यादा: डावीकडील (Left Side) डेटा शोधता येत नाही, आणि मध्ये नवीन कॉलम इन्सर्ट केल्यास फॉर्म्युला ब्लॉक होतो.
2. XLOOKUP Deep Breakdown Excel 365/2021+
VLOOKUP व HLOOKUP चा आधुनिक शक्तिशाली पर्याय.
=XLOOKUP(lookup_val, lookup_array, return_array, [if_not_found], [match_mode], [search_mode])
=XLOOKUP("Laptop", Lookup_Master!A2:A17, Lookup_Master!C2:C17, "Not Found")
✨ XLOOKUP चे फायदे:
१) डाव्या बाजूचा (Left Lookup) डेटा सहजरित्या शोधतो.
२) Column index मोजावा लागत नाही.
३) Exact Match बाय-डिफॉल्ट करतो.
४) न सापडल्यास संदेश देण्याची सोय [if_not_found] मध्ये उपलब्ध!
3. INDEX + MATCH (2D Dynamic Matrix) Dynamic Reference
रिव्हर्स लूकअप आणि २-वे टेबल मॅट्रिक्स शोधण्यासाठी.
=INDEX(return_column, MATCH(lookup_val, lookup_column, 0))
=INDEX(Lookup_Master!D2:D17, MATCH(G2, Lookup_Master!A2:A17, 0))
4. IFERROR & IFNA Error Handling Error Handling
#N/A किंवा #VALUE! चुका लपवून रिपोर्ट नीट ठेवणे.
=IFERROR(VLOOKUP(A2, Master!A:C, 3, FALSE), "Check Product Name")

⚠️ Module 13: Excel Errors & Diagnostic Troubleshooting Guide

Excel Common Errors & Solutions Troubleshooting
#N/A ➔ Value Not Available (VLOOKUP key न सापडणे). IFERROR वापरा किंवा TRIM करा.
#VALUE! ➔ Wrong Data Type (नंबर ऐवजी टेक्स्टची बेरीज करणे). VALUE() वापरा.
#REF! ➔ Invalid Cell Reference (रो किंवा कॉलम डिलीट झाल्याने तुटलेली लिंक).
#DIV/0! ➔ Division by Zero (शून्याने भागणे). IF(B2=0, 0, A2/B2) लिहा.
#NAME? ➔ Formula Spelling Typo (फॉर्म्युला नाव चुकीचे असणे किंवा unquoted text).
##### ➔ Column Width Small (कॉलमची रुंदी कमी पडणे). बॉर्डरवर डबल क्लिक करा.
#SPILL! ➔ Dynamic Array Spill Blocked (खालील सेल्समध्ये डेटा असल्याने जागा अडकणे).
