🔒 Cell References (Bahut Important Concept)

1. Reference Types & Dollar ($) Locking References
Excel me 3 types ke cell references hote hain — advance formulas ke liye ye samajhna zaroori hai:
TypeExampleBehaviour when copied
Relative ReferenceA1Formula copy karne par cell address automatically change hota hai.
Absolute Reference$A$1Formula copy/drag karne par cell bilkul FIX (Lock) rehta hai.
Mixed Reference (Col Lock)$A1Column fix rehta hai, row change hoti hai.
Mixed Reference (Row Lock)A$1Row fix rehti hai, column change hota hai.
💡 Practical Example: Agar tumhe ek fixed tax rate (jo cell $B$1 me hai) sabhi rows me multiply karna hai, to tax rate cell ko $B$1 bana do. Drag karne par wo change nahi hoga!
⚡ Pro Tip: Press F4 key while editing a formula to quickly cycle between Relative ➔ Absolute ➔ Mixed references!

🧠 Module 1: Logical Functions (IF, IFS, AND, OR, NOT, IFERROR, IFNA, SWITCH)

1. IF Function Syntax Logical
Basic condition check karke TRUE ya FALSE output dene ke liye.
=IF(condition, value_if_true, value_if_false)
=IF(A2>=40, "Pass", "Fail")
=IF(E5>=15000, E5*5%, 0)
2. IFS & Nested IF Replacement Excel 2019+
Multiple conditions ek sath check karne ke liye (Nested IF ka clean replacement).
=IFS(cond1, val1, cond2, val2, ...)
=IFS(A2>=90,"A", A2>=75,"B", A2>=50,"C", TRUE,"Fail")
3. AND, OR & NOT Functions Multi-Condition
Complex logic rules setup karne ke liye:
=IF(AND(A2>=50, B2>=50), "Pass", "Fail") ➔ Sabhi conditions TRUE honi chahiye
=IF(OR(A2<0, B2<0), "Error", "OK") ➔ Kam se kam ek condition TRUE
=NOT(A2="") ➔ Condition ko reverse karta hai
4. IFERROR & IFNA Error Handling Error Guard
Formulas me error aane par clean custom message dikhane ke liye.
=IFERROR(VLOOKUP(A2, B:C, 2, 0), "Not Found")
=IFNA(VLOOKUP(A2, B:C, 2, 0), "Value Not Available")

🔍 Module 2: Lookup & Reference Functions (VLOOKUP, HLOOKUP, XLOOKUP, INDEX+MATCH)

1. VLOOKUP & HLOOKUP Classic Lookup
Vertical aur Horizontal tables me data lookup karne ke liye.
=VLOOKUP(lookup_value, table_array, col_index_num, range_lookup)
=VLOOKUP(A2, Sheet2!$A$2:$D$100, 3, 0)
⚠️ Rule: range_lookup = 0 (FALSE) matlab exact match. Always use 0 unless approximate match is needed!
2. XLOOKUP (Modern & Best — Excel 365/2021+) Excel 365+
VLOOKUP se bahut better hai — Left Side bhi search karta hai, exact match default hai aur built-in error handling hai.
=XLOOKUP(lookup_value, lookup_array, return_array, [if_not_found], [match_mode], [search_mode])
=XLOOKUP(A2, Names, Salary, "Not Found")
3. INDEX + MATCH Combo & Other Lookups Advanced
VLOOKUP ka sabse powerful alternative jo Large Datasets par Fast chalta hai.
=INDEX(return_range, MATCH(lookup_value, lookup_range, 0))
=OFFSET(reference, rows, cols, [height], [width]) ➔ Dynamic range
=INDIRECT("Sheet2!A1") ➔ Text ko cell reference me convert karta hai
=CHOOSE(2, "Low", "Medium", "High") ➔ "Medium"

💼 Module 19: Job Best Practices & 20 Practical Scenarios

7 Golden Job Best Practices Job Tips
1. Hardcoded numbers formulas me mat use karo — named ranges/cells use karo.
2. Har naye data ke liye Excel Table (Ctrl+T) use karo.
3. Absolute reference ($A$1) ka use samajh ke karo.
4. XLOOKUP > VLOOKUP prefer karo agar Excel 365 available hai.
5. Large data me SUMPRODUCT/array formulas heavy ho sakte hain — INDEX-MATCH ya Power Query prefer karo.
6. Pivot Tables ko manually refresh (Ctrl+Alt+F5) karna mat bhoolo.
7. Macro-enabled workbook ko .xlsm me hi save karo!
