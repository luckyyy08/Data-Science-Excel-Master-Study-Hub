🧠 Module 1: Logical Functions (लॉजिकल फॉर्म्युले)
Logical Condition
➔
TRUE: Output 1
➔
FALSE: Output 2
1. IF Function Logical
कन्डिशन तपासून TRUE किंवा FALSE आऊटपुट देण्यासाठी.
=IF(logical_test, value_if_true, value_if_false)
=IF(Salary>=15000, "Eligible", "Not-Eligible")
=IF(E5>=15000, E5*5%, 0)
💡 मराठीत: जर Salary १५,००० पेक्षा जास्त असेल तर ५% बोनस द्या, नाहीतर ० द्या.
2. IFS Function Logical (Excel 2019+)
अनेक अटी (Multiple Conditions) एकाच फॉर्म्युल्यात मांडण्यासाठी.
=IFS(condition1, val1, condition2, val2, ...)
=IFS(C3>=1000000, "30%", C3>=500000, "20%", C3>=250000, "5%", C3<250000, "NO TAX")
💡 मराठीत: इन्कम टॅक्स स्लॅब कॅल्क्युलेशनसाठी अतिशय सोपा फॉर्म्युला! एकापेक्षा जास्त Nested IF लिहिण्याऐवजी IFS वापरावा.
3. AND & OR Functions Logical
अनेक अटी एकत्र जोडण्यासाठी.
=IF(AND(C5="Borivali", E5>35000), 1000, 0)
=IF(OR(Branch="Borivali", Salary>=15000), "Yes", "No")
💡 AND: सर्व अटी पूर्ण झाल्या तरच TRUE.
💡 OR: कोणतीही एक अट पूर्ण झाली तरी TRUE.
4. NESTED IF Logical
एका IF मध्ये दुसरा IF वापरणे.
=IF(C7="High", D7-5, IF(C7="Medium", D7-3, IF(C7="Low", D7-1, "")))
💡 उदा (SMS Matrix): Risk Flag जर "High" असेल तर EMI तारखेच्या ५ दिवस आधी SMS पाठवा, "Medium" असेल तर ३ दिवस आधी पाठवा.
📌 Teacher's Logical Pro Tip:
१. Text व्हॅल्यू नेहमी double quotes " " मध्ये लिहा (उदा: "Borivali"). पण नंबर किंवा सेल रेफरन्स " " मध्ये लिहू नका!
२. IFS वापरताना मोठ्या संख्येकडून लहान संख्येकडे ऑर्डर ठेवावी (उदा: १० लाख ➔ ५ लाख ➔ २.५ लाख).
📊 Module 2: Conditional Aggregation (SUMIF, COUNTIF & SUBTOTAL)
1. SUMIF & SUMIFS Math & Trig
अटीवर आधारित बेरीज (Conditional Total) करण्यासाठी.
=SUMIF(range, criteria, [sum_range])
=SUMIFS(sum_range, criteria_range1, criteria1, criteria_range2, criteria2)
=SUMIF(Designation, "Manager", Salary)
=SUMIFS(Amount, Transaction_Type, "Online", Debit_Credit, "Credit")
💡 महत्त्वाचा फरक: SUMIF मध्ये sum_range शेवटी असतो, तर SUMIFS मध्ये sum_range सर्वात आधी लिहावा लागतो!
2. COUNT Family Statistical
सेल्स मोजण्यासाठी (Counting Cells).
=COUNT(range) ➔ फक्त Numbers मोजते
=COUNTA(range) ➔ भरलेले सर्व सेल्स (Text + Numbers)
=COUNTBLANK(range) ➔ रिकामे सेल्स (Empty Cells)
=COUNTIF(Transaction_Type, "UPI")
=COUNTIFS(Transaction_Type, "UPI", Debit_Credit, "Debit")
3. AVERAGEIF & AVERAGEIFS Statistical
अटीवर आधारित सरासरी (Average) काढण्यासाठी.
=AVERAGEIF(range, criteria, [average_range])
=AVERAGEIFS(Amount, Transaction_Type, "Card", Debit_Credit, "Credit")
4. SUBTOTAL & SUMPRODUCT Advanced Math
फिल्टर केलेल्या डेटावर गणना करणे आणि गुणाकारांची बेरीज करणे.
=SUBTOTAL(9, C2:C100) ➔ Hidden rows सोडून SUM
=SUMPRODUCT(Qty_Range, Rate_Range)
=SUMPRODUCT(C2:C10, D2:D10) ➔ (Qty * Rate) ची Total
💡 SUBTOTAL code 9: फिल्टर केल्यावर फक्त दिसणाऱ्या (Visible) रो चीच Total दाखवतो!
🔤 Module 3: Text Manipulation Functions (टेक्स्ट फॉर्म्युले)
1. LEFT, MID, RIGHT Text
टेक्स्ट मधील शब्द किंवा अंक वेगळे (Extract) करण्यासाठी.
=LEFT(text, num_chars) ➔ डावीकडून
=RIGHT(text, num_chars) ➔ उजवीकडून
=MID(text, start_num, num_chars) ➔ मधून
=LEFT("Mumbai - 400086", 6) ➔ "Mumbai"
=RIGHT("Mumbai - 400086", 6) ➔ "400086"
=MID("IV-RAHUL-986", 4, 5) ➔ "RAHUL"
2. FIND & SUBSTITUTE Text
अक्षर शोधणे आणि बदलणे.
=FIND(find_text, within_text)
=SUBSTITUTE(text, old_text, new_text)
=SUBSTITUTE("9812-34-56-78", "-", "") ➔ "9812345678"
⚡ Flash Fill (Ctrl + E): फॉर्म्युला न वापरता नमुना टाईप करून ऑटोमॅटिक डेटा वेगळा करण्यासाठी Ctrl + E वापरा!
3. PROPER, UPPER, LOWER Text
अक्षरांचा आकार (Case) बदलण्यासाठी.
=PROPER("barack hussein") ➔ "Barack Hussein"
=UPPER("mumbai") ➔ "MUMBAI"
=LOWER("EXCEL") ➔ "excel"
4. TRIM, LEN, SEARCH & CONCAT Text Utility
टेक्स्ट मधील स्पेस काढणे, लांबी मोजणे व शोधणे.
=TRIM(text) ➔ अतिरिक्त मोकळ्या जागा (Extra Spaces) काढण्यासाठी
=LEN(text) ➔ अक्षरांची एकूण संख्या मोजण्यासाठी
=SEARCH(find_text, within_text) ➔ अक्षराचा क्रमांक शोधणे
=CONCAT(text1, text2) ➔ दोन किंवा अधिक शब्द एकत्र जोडणे
=TRIM(" Rahul Dravid ") ➔ "Rahul Dravid"
=LEN("Mumbai") ➔ 6
💡 TRIM & LEN: डेटा क्लीनिंग करताना नावांमधील अतिरिक्त स्पेस काढून लांबी तपासण्यासाठी अतिशय उपयुक्त!
📅 Module 4: Date & Time Functions (तारीख व वेळ फॉर्म्युले)
1. Basic Date Functions Date & Time
आजची तारीख व वेळेवर काम करणे.
=TODAY() ➔ आजची तारीख
=NOW() ➔ तारीख + वेळ
=YEAR(A6), =MONTH(A6), =DAY(A6)
=TEXT(A6, "dddd") ➔ वार (Day Name e.g. "Monday")
=TEXT(A6, "mmmm") ➔ महिन्याचे नाव (e.g. "August")
2. Advanced Date Calculations Date & Time
वय (Age), मॅच्युरिटी डेट व कामाचे दिवस मोजणे.
=DATEDIF(BirthDate, TODAY(), "Y") & " Years"
=EDATE(StartDate, 6) ➔ ६ महिन्यांनंतरची तारीख
=EOMONTH(StartDate, 0) ➔ चालू महिन्याचा शेवटचा दिवस
=NETWORKDAYS(StartDate, EndDate, Holidays)
💡 NETWORKDAYS: शनिवार, रविवार आणि सुट्ट्या सोडून शुद्ध कामाचे दिवस मोजते!
3. NETWORKDAYS.INTL & DAYS Custom Dates
कस्टम सुट्ट्या व तारखांमधील एकूण दिवस.
=NETWORKDAYS.INTL(start_date, end_date, [weekend], [holidays])
=DAYS(end_date, start_date)
=WEEKDAY(serial_number, [return_type])
=NETWORKDAYS.INTL(A11, B11, 11, A14:A17)
💡 INTL काय करतो?: जर सुट्टी फक्त रविवारीच असेल (Weekend = 11), तर NETWORKDAYS.INTL वापरून काम मोजता येते!
📅 Date Cheat Sheet:
- =TEXT(A1, "dd-mmm-yyyy") ➔ 03-Aug-2026
- =DATEDIF(A1, B1, "M") ➔ दोन तारखांमधील एकूण महिने
- =WORKDAY(TODAY(), 10, Holiday_Range) ➔ १० काम करण्याच्या दिवसांनंतर येणारी तारीख.
🗄️ Module 5: Database Functions (DSUM, DAVERAGE, DCOUNT)
DSUM, DAVERAGE, DCOUNT, DMAX, DMIN Database
टेबलवर स्ट्रक्चरल क्रायटेरिया (Criteria Range) लावून गणना करणे.
=DSUM(database, field, criteria)
=DAVERAGE(database, field, criteria)
=DCOUNT(database, field, criteria)
=DSUM(A1:F100, "Salary", H1:I2)
💡 फायदा: यात Criteria चे वेगळे मिनी-टेबल तयार करून हवा तसा मल्टी-कॉलम डेटा फिल्टर करून टोटल काढता येते!
💰 Module 6: Financial Functions (EMI, PMT, IPMT, PPMT)
PMT, IPMT & PPMT Financial
कर्जाचे हप्ते (EMI), व्याज (Interest) व मुद्दल (Principal) काढण्यासाठी.
=PMT(rate/12, nper, -pv) ➔ महिन्याचा एकूण EMI
=IPMT(rate/12, per, nper, -pv) ➔ ठराविक हप्त्याचे व्याज
=PPMT(rate/12, per, nper, -pv) ➔ ठराविक हप्त्याची मुद्दल
=PMT(10%/12, 60, -500000)
💡 महत्त्वाची टीप: वार्षिक व्याजाला १२ ने भागा (Rate/12) आणि वर्षाचे महिने करा (Years * 12). कर्जाची रक्कम माइनस (-) मध्ये टाकावी लागते!
