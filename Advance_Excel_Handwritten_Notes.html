🧠 Module 1: Logical Functions (लॉजिकल फॉर्म्युले)

1. IF Function Logical
कन्डिशन तपासून TRUE किंवा FALSE आऊटपुट देण्यासाठी.
=IF(Salary>=15000, "Eligible", "Not-Eligible")
=IF(E5>=15000, E5*5%, 0)
💡 मराठीत: जर कर्मचाऱ्याचा पगार ₹१५,००० किंवा त्यापेक्षा जास्त असेल तर त्याला ५% बोनस द्या, नाहीतर ० द्या.
2. IFS Function Excel 2019+
अनेक अटी (Multiple Conditions) एकाच फॉर्म्युल्यात मांडण्यासाठी.
=IFS(C3>=1000000, "30%", C3>=500000, "20%", C3>=250000, "5%", C3<250000, "NO TAX")
💡 Income Tax Calculation: १० लाखांपेक्षा जास्त उत्पन्नावर ३०% टॅक्स, ५ ते १० लाखांवर २०%, आणि २.५ लाखांपेक्षा कमी उत्पन्नावर नो टॅक्स.
3. AND & OR Functions Multi-Condition
अनेक अटी एकत्र जोडण्यासाठी.
=IF(AND(Branch="Borivali", Salary>=15000), Employee_Name, "")
=IF(OR(Branch="Borivali", Salary>=15000), "Eligible", "Not Eligible")
💡 AND: सर्व अटी पूर्ण झाल्या तरच TRUE.
OR: कोणत्याही एका अट पूर्ण झाल्यास TRUE.

📊 Module 2: Conditional Aggregation (SUMIF, COUNTIF & SUBTOTAL)

1. SUMIF vs SUMIFS Aggregation
अटीनुसार बेरीज करणे.
=SUMIF(Designation, "Manager", Salary)
=SUMIFS(Amount, Transaction_Type, "Online", Debit_Credit, "Credit")
💡 SUMIFS मध्ये पहिला आर्ग्युमेंट sum_range (बेरीज करायचा कॉलम) असतो!
2. COUNT & Statistical Family Statistics
सेल्स मोजण्यासाठी व आकडेवारी काढण्यासाठी.
=COUNT(C3:T15) ➔ फक्त numbers असणारे सेल्स
=COUNTA(C3:U15) ➔ भरलेले सर्व सेल्स (Text+Num)
=COUNTIF(Trans_Type, "Debit") ➔ अटीनुसार मोजणे
=MEDIAN(J7:J44) ➔ मध्यक संख्या काढणे
3. SUBTOTAL Function Filtered Sum
फिल्टर केलेल्या डेटावर अचूक बेरीज व सरासरी काढणे.
=SUBTOTAL(9, C3:C100) ➔ Filtered Visible Cells Total
=SUBTOTAL(109, C3:C100) ➔ Manually Hidden + Filtered Total
💡 कोड ९: SUM ची बेरीज करण्यासाठी वापरतात.

🔍 Module 8: Lookup & Reference Masterclass (XLOOKUP, INDEX+MATCH)

1. XLOOKUP Function Excel 365/2021+
VLOOKUP चा आधुनिक पर्याय. डावीकडील (Left Side) डेटा सहज शोधतो.
=XLOOKUP(lookup_value, lookup_array, return_array, [if_not_found])
=XLOOKUP("Laptop", Lookup_Master!A2:A17, Lookup_Master!C2:C17, "Not Found")
💡 Column index मोजावा लागत नाही आणि अचूक मॅच (Exact Match) बाय-डिफॉल्ट करतो!
2. INDEX + MATCH Combination 2D Dynamic
डायनामिक रिव्हर्स लूकअपसाठी सर्वोत्तम कॉम्बिनेशन.
=INDEX(return_column, MATCH(lookup_value, lookup_column, 0))
=INDEX(Lookup_Master!D2:D17, MATCH(G2, Lookup_Master!A2:A17, 0))
3. IFERROR Function Error Handling
#N/A किंवा #VALUE! चुका लपवून स्वच्छ आऊटपुट दाखवण्यासाठी.
=IFERROR(VLOOKUP(A2, Master!A:C, 3, FALSE), "Check Product Name")

⚡ Module 9: Dynamic Array Formulas (UNIQUE, FILTER, SORTBY)

1. UNIQUE Function Dynamic Array
मोठ्या डेटामधून डुप्लिकेट्स वगळून युनिक नावांची लिस्ट काढणे.
=UNIQUE(Raw_Sales_Data!E2:E501)
2. FILTER Function Dynamic Filter
अटीनुसार संपूर्ण टेबलचा डेटा ऑटोमॅटिकली फिल्टर करणे.
=FILTER(Raw_Sales_Data!A2:M501, Raw_Sales_Data!F2:F501="Electronics", "No Records")
3. SORTBY Function Dynamic Sort
दुसऱ्या कॉलमच्या आधारे संपूर्ण टेबल सॉर्ट करणे.
=SORTBY(Lookup_Master!A2:C17, Lookup_Master!C2:C17, -1)
